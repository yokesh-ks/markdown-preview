# Contributing to Markdown Preview

Thank you for your interest in contributing to this project! We welcome contributions from everyone. This document provides guidelines and instructions for contributing.

## Code of Conduct

This project adheres to the Contributor Covenant Code of Conduct. By participating, you are expected to uphold this code. Please report unacceptable behavior to conduct@project.dev.

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager
- Git

### Setup

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/markdown-preview.git`
3. Add upstream remote: `git remote add upstream https://github.com/yokesh-ks/markdown-preview.git`
4. Install dependencies: `npm install`
5. Create a feature branch: `git checkout -b feature/your-feature-name`

## Development

### Running Tests

```bash
npm test
```

### Building

```bash
npm run build
```

### Code Style

- Follow ESLint configuration in the project
- Use Prettier for code formatting
- Run `npm run lint` to check code quality

## Submitting Changes

1. Make your changes in a feature branch
2. Write or update tests as necessary
3. Update documentation if needed
4. Commit with clear, descriptive messages
5. Push to your fork
6. Open a Pull Request with a clear description

## Pull Request Process

1. Ensure all tests pass
2. Update the README if you've changed functionality
3. Include relevant issue numbers in the PR description
4. Wait for code review and address any feedback
5. A maintainer will merge your PR once approved

## Reporting Issues

Before creating a bug report, please check the issue tracker. When creating a bug report, include:

- Clear, descriptive title
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots if applicable
- Environment details (OS, Node version, etc.)

## Questions?

Feel free to open a Discussion or ask in the Discussions section of the repository.

Thank you for contributing!
